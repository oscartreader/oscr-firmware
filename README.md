# Open Source Cartridge Reader

Welcome! We've recently switched to this new repository and are still getting things set up. Additionally, as the firmware has been completely reworked, you should consider this repository highly experimental. As such you should only use it if you want to help with testing or development.

For most users, we still recommend to use the previous firmware, available here: https://github.com/sanni/cartreader
